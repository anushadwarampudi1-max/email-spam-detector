# AI Email Spam Detector

An AI-based web application that detects whether an email is Spam or Not Spam.

## Features

- User Sign Up and Login
- AI-based Email Spam Detection
- Spam and Not Spam prediction
- Simple and user-friendly web interface
- SQLite database for user accounts

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- HTML
- CSS
- SQLite

## How It Works

1. User creates an account or logs in.
2. User enters an email message.
3. The AI model analyzes the email.
4. The system predicts whether it is Spam or Not Spam.
5. The result is displayed on the screen.

## Project Purpose

The project helps users identify potentially unwanted or suspicious email messages using machine learning.
